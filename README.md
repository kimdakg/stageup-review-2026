# 2026 스테이지 업 리뷰 · 김다경

셀프 리뷰와 주요 성과를 담은 검토본입니다. 본문은 번호와 기호로만 구분한 일반 텍스트입니다.

- [리뷰 본문 보기](review.txt)
- [GitHub Pages 설정 열기](https://github.com/kimdakg/stageup-review-2026/settings/pages)

Pages 설정에서 Source를 Deploy from a branch로, Branch를 main / (root)로 지정하고 Save를 누릅니다. 배포가 완료되면 Pages에 표시되는 Visit site 주소를 공유합니다.

수정하기, 완료, 본문 복사, HTML 저장, 포트폴리오 첨부 및 다운로드를 지원합니다.

포트폴리오 파일은 페이지 상단의 파일첨부 버튼에서 안내하는 GitHub Releases 업로드 화면에 등록합니다. 처음 등록할 때 태그는 portfolio, 제목은 포트폴리오로 입력하고 파일을 첨부한 뒤 Publish release를 누릅니다. 파일 1개, 최대 200MB(200,000,000바이트)까지 리뷰에 연결되며, 여러 파일은 ZIP 파일 하나로 압축합니다. 초과 용량이나 여러 첨부파일이 확인되면 다운로드 버튼 대신 교체 안내가 표시됩니다. GitHub 자체의 업로드 한도와 별도로 리뷰에 연결할 파일의 용량을 검사합니다.

페이지는 가장 최근에 공개한 릴리스의 첨부파일을 조회합니다. 초안 릴리스는 표시하지 않습니다. 파일 등록과 교체는 저장소 쓰기 권한이 있는 작성자만 GitHub 화면에서 진행하며, 리더는 로그인 없이 다운로드할 수 있습니다. 등록 후 리뷰 페이지의 새로고침 버튼으로 첨부 상태를 확인할 수 있습니다. 연결 또는 조회 제한이 있으면 GitHub의 공개 첨부파일 목록으로 이동하는 링크가 표시됩니다.

완료를 누르면 현재 브라우저에 저장됩니다. 공개된 페이지를 바꾸려면 HTML 저장으로 받은 index.html을 저장소에 다시 업로드해야 합니다. 공개 페이지 방문자가 자신의 브라우저에서 편집하더라도 다른 사람에게 보이는 원본은 바뀌지 않습니다.
