# 2026 스테이지 업 리뷰 · 김다경

셀프 리뷰와 주요 성과를 담은 검토본입니다. 본문은 번호와 기호로만 구분한 일반 텍스트입니다.

- [리뷰 본문 보기](review.txt)
- [GitHub Pages 설정 열기](https://github.com/kimdakg/stageup-review-2026/settings/pages)

Pages 설정에서 Source를 Deploy from a branch로, Branch를 main / (root)로 지정하고 Save를 누릅니다. 배포가 완료되면 Pages에 표시되는 Visit site 주소를 공유합니다.

수정하기, 완료, 본문 복사, 기본 맞춤법 검사, HTML 저장을 지원합니다. 맞춤법 검사는 자주 틀리는 표기와 띄어쓰기 규칙을 점검하며 문맥 전체를 검증하지는 않습니다.

완료를 누르면 현재 브라우저에 저장됩니다. 공개된 페이지를 바꾸려면 HTML 저장으로 받은 index.html을 저장소에 다시 업로드해야 합니다. 공개 페이지 방문자가 자신의 브라우저에서 편집하더라도 다른 사람에게 보이는 원본은 바뀌지 않습니다.
